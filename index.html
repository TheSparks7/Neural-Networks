A neural network maps inputs to outputs through connected layers. During training, its weights are adjusted using examples; once trained, it can use those learned values to make predictions.

Each connection has a weight; each neuron transforms its inputs.

Signals pass from the input layer through hidden layers to the output layer. Each unit transforms its inputs before sending a value onward.

For digit recognition, an image is the input and the model returns a score for each possible digit. The interactive demo below uses a pretrained network to make that prediction.

01 / Model

The network

A neural network is made of layers of connected units. Each unit combines its inputs using learned weights and a bias, then applies an activation function. The layers work together to transform an input into a prediction.

02 / Neurons

Neurons

A neuron calculates a weighted sum of its inputs, adds a bias, and applies an activation function. Its output is passed to units in the next layer. This is a simplified mathematical model, not a description of how biological neurons work.

03 / Weights

Weights

A weight scales the signal sent along a connection: larger magnitudes have more influence, while the sign affects its direction. Training adjusts weights and biases to reduce prediction error; they are learned values, not new program instructions.

04 / Layers

Layers

The input layer receives the data, hidden layers transform it, and the output layer produces a prediction. What each layer learns depends on the network architecture and training data; visual features such as edges are one example, not a rule for every network.

05 / Activation

Activation

An activation function adds nonlinearity after a unit combines its inputs. Without nonlinear activations, stacking linear layers is still equivalent to a single linear transformation. ReLU, sigmoid, and tanh are common examples, each with different properties and uses.

06 / Learning

Learning

Training repeats a forward pass and measures the prediction error with a loss function. Backpropagation calculates gradients that show how each weight and bias contributes to that loss; an optimizer, such as gradient descent, uses those gradients to update the parameters. Repeating this process can reduce error, but it does not guarantee every prediction will be correct.

01 / Input

A drawing becomes an image

The canvas stores your white strokes on a black background at 280 × 280 pixels. Before the model sees them, the demo scans for the drawn area and crops the image to the ink. The network receives numerical pixel values, not the abstract idea of a handwritten digit.

REFERENCE / KERAS — MNIST DATASET

02 / Preprocessing

Preparing the input

The cropped drawing is resized so its longest side is 20 pixels, then placed on a 28 × 28 black frame and centered by its ink intensity. The demo scales each grayscale pixel from 0–255 to 0–1 and shapes the values into a single-image tensor before inference. Matching the model’s expected input format is essential for a useful prediction.

REFERENCE / KERAS — MNIST IMAGE PREPROCESSING

03 / Computation

The forward pass

The page loads a pretrained model and passes the prepared tensor to its prediction function. Inside a network, each layer transforms the values it receives and passes results onward until they reach the output. The model’s layer configuration lives in the downloaded model file, rather than being specified by this page.

REFERENCE / GOOGLE — NODES AND HIDDEN LAYERS

04 / Transformation

Why layers matter

Hidden layers can build useful representations by transforming signals between the input and output. Nonlinear activation functions let a network represent patterns that a stack of linear operations alone cannot. This site does not specify the loaded model’s exact layers or activation functions, so the demo should not be read as a visualization of those internal details.

REFERENCE / GOOGLE — ACTIVATION FUNCTIONS

05 / Classification

Ten possible digits

The model returns a score for each digit from 0 to 9. The demo selects the digit with the largest returned value and displays all ten scores as bars. They are model outputs shown for comparison, not a separately verified accuracy measure or calibrated confidence.

REFERENCE / GOOGLE — NEURAL NETWORKS

06 / Training

Trained, not learning

The demo downloads a pretrained model and uses its fixed parameters to make predictions; drawing a digit does not train or update it. During training, a separate process can use prediction errors and their gradients to update weights and biases. That learning process happened before this interactive demo runs.
