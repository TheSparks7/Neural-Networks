An artificial neural network is a computational model inspired by biological neural networks. It consists of connected units called artificial neurons.

Each connection has a weight; each neuron transforms its inputs.

Signals travel from an input layer, through any hidden layers, to an output layer. Each neuron processes incoming signals and applies a nonlinear activation function before passing its output onward.

During training, the network adjusts connection weights using examples. Those weights shape its outputs and let it make predictions on new inputs.

01 / Model

The network

At its core, an artificial neural network is just a bunch of math nodes wired together to loosely mimic how biological brains process information. Data enters through an input layer, bounces through a series of hidden layers where the real heavy lifting happens, and spits out a result at the end. It figures things out not by following a rigid rulebook, but by constantly tweaking how strongly these connected nodes talk to each other.

02 / Neurons

Neurons

An individual neuron is basically a tiny decision-maker. It takes a bunch of inputs, multiplies each by a specific weight to see how much it should actually care about them, adds them all up, and pushes the total through an activation function. Whatever survives that process gets passed down the line to feed the next layer.

03 / Weights

Weights

Weights are the actual knobs and dials of the network. Every connection has one, acting as a multiplier that decides whether a signal gets amplified or muted. When a network learns, it isn't rewriting its own source code at all; rather it's just slowly turning these dials until the math finally adds up to the right answers.

04 / Layers

Layers

Instead of dumping everything into one chaotic mess, neurons are stacked into organized tiers. The input layer takes raw data as it is, the output layer gives you the final guess, and all the hidden layers in between do the tedious work of breaking down patterns that turn raw pixels into edges, edges into shapes, and shapes into actual concepts.

05 / Activation

Activation

Without activation functions, stacking a million layers together is completely pointless because, mathematically speaking, multiple linear steps just collapse into one giant, boring straight line. Functions like ReLU, sigmoid, or tanh inject a bit of necessary non-linearity, allowing the network to wrap its head around complicated, messy real-world data instead of oversimplifying everything.

06 / Learning

Learning

Training is essentially an endless loop of making mistakes and adjusting course. The network takes a guess, checks how far off it was from the actual answer, and sends that error report backward through the system. Through a process called backpropagation and gradient descent, every single weight gets a tiny nudge in the right direction until the network stops screwing up quite so much.
