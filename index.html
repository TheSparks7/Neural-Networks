A neural network maps inputs to outputs by a series of connected layers. It is trained by adjusting its weights on the basis of examples. Once trained it can then use those learned weights to make predictions.

Each connection has a weight. Each neuron takes its inputs and transforms them.

Signals pass from the input layer through the hidden layers to the output layer. Each unit takes its inputs and transforms them before sending a value on.

For digit recognition you've got an image as an input and the model outputs a score for each of the possible digits. The interactive demo below makes that prediction using a pre-trained network.

01 / Model

The network

A neural network is made up of layers of units, each of which takes its inputs, combines them using learned weights and a bias and then applies an activation function. The layers work together to transform the input into a prediction.

02 / Neurons

Neurons

A neuron computes a weighted sum of its inputs, adds a bias and then applies an activation function. Its output is then passed on to the units in the next layer. That's the basic mathematical model, not a description of how a biological neuron actually works.

03 / Weights

Weights

A weight scales the signal that gets passed along a connection: larger weights have a greater influence, the sign of the weight determines the direction of influence. The weights and biases are adjusted during training in order to reduce the prediction error. They are learned values, not new instructions that we've programmed in.

04 / Layers

Layers

The input layer takes in the data, the hidden layers do the transforming and the output layer produces the prediction. What the various layers learn is entirely dependent on the architecture of the network and the data it's trained on. Edges are one example of the kind of visual feature that a network might learn.

05 / Activation

Activation

An activation function is one that introduces non-linearity after a unit has combined its inputs. Without some form of non-linearity then stacking linear layers is effectively just a single linear transformation. The various activation functions we're used to (ReLU, sigmoid, tanh etc) all have different characteristics and are used in different situations.

06 / Learning

Learning

Training involves repeating a forward pass and measuring the prediction error via a loss function. Backprop is then used to calculate the gradients which tell you how much each weight and each bias contributed to that loss. An optimiser (typically gradient descent) uses those gradients to update the parameters. Carrying out this process over and over can reduce the error, but it doesn't guarantee that every prediction will be correct.

From pixels to prediction.

01 / Input

A drawing becomes an image

The canvas stores your white strokes against a black background at 280x280 pixels. Prior to the model seeing it, the demo will scan for the area that's been drawn and crop the image to just that. The network receives the pixel values as numbers rather than the concept of a handwritten digit.

REFERENCE / KERAS — MNIST DATASET

02 / Preprocessing

Preparing the input

The cropped drawing is resized so that its longest side is 20 pixels and then placed on a 28 x 28 black frame with the image centred by its ink intensity. The demo rescales each of the grayscale pixels from 0-255 to 0-1 and then shapes them into a single image tensor prior to inference. It's absolutely essential that the input matches the model's expected format in order for the prediction to be of any use.

REFERENCE / KERAS — MNIST IMAGE PREPROCESSING

03 / Computation

The forward pass

The page loads a pre-trained model and feeds it the prepared tensor via its prediction function. Within a network each layer takes the values it receives, transforms them and passes the results on until they get to the output. The architecture of the network (i.e. the layer configuration) is all contained within the model file that's been downloaded.

REFERENCE / GOOGLE — NODES AND HIDDEN LAYERS

04 / Transformation

Why layers matter

Hidden layers can of course learn to build up useful representations by transforming the signal as it passes from input to output. Non-linear activation functions allow the network to represent patterns which a simple stack of linear operations would be unable to. This site doesn't specify what the loaded model's actual layers are or what its activation functions are so the demo should not be interpreted as a visualization of those internal layers.

REFERENCE / GOOGLE — ACTIVATION FUNCTIONS

05 / Classification

Ten possible digits

The model returns a score for each digit from 0 to 9. The demo takes the digit with the highest score and then displays all the ten scores as bars. Those are the model outputs for comparison, not some independently verified accuracy or calibrated confidence.

REFERENCE / GOOGLE — NEURAL NETWORKS

06 / Training

Trained, not learning

The demo downloads a pre-trained model and then uses the fixed parameters of that model to make its predictions. Drawing a digit in no way trains or updates the model. During the training phase a separate process would use the prediction errors and their gradients to update the weights and biases. That learning has already occurred prior to this interactive demo even being run.

Applications

Where it ships

Neural nets are no longer just a subject of academic research. They form the computational bedrock of a whole host of modern technologies. We use them in clinical diagnostics, we use them for fraud detection, we use them for real time speech translation and we use them for autonomous navigation. They're the engine that turns the maths into something that actually works.

01 / Healthcare

Healthcare

Neural nets can look at X-rays, MRIs and pathology slides far faster than a radiologist can blink. They can detect tumours, segment organs and predict patient risk by learning the patterns that are present in millions of scans (patterns which are simply too subtle for the human eye to pick up consistently).

02 / Finance

Finance

Every time an online purchase is instant approved or flagged for verification a neural network is at work. It's looking at hundreds of subtle behavioural signals (purchase frequency, device data, spending patterns etc) in the space of a few milliseconds and doing a risk assessment that would take a human analyst hours to do.

03 / Language

Language

Translation, autocomplete, summarisation, chat... the text you read online is increasingly being funneled through transformer networks. They take words and map them into dense vector spaces, then learn what the relationships between those vectors are, enabling a single model to do translation, answer questions and write prose that it was never explicitly taught.

04 / Vision

Vision

Convolutional nets power the cameras that unlock your phone, the checkout that reads your receipt and the quality control line that spots a cracked lens before it even gets shipped. Each layer learns a slightly more abstract feature; edges, then textures, then whole objects - until the final layer knows what it's looking at.

05 / Autonomy

Autonomy

Self driving stacks combine the camera, lidar and radar into a single perception model which can then predict what every object around the car is going to do next. The neural networks do the detection, the tracking, the trajectory forecasting and the control all in real time at 30fps.

Conclusion

A model of the world.

What looks like intelligence on a screen is at its heart just an exercise in geometry. When you scribbled that digit into the browser demo earlier, the system didn't read your handwriting at all. It was simply working out a series of probabilities through a chain of weights and activations. It removes all the mystique and what you're left with is just numbers.

But there's still a very clear line between calculation and understanding. The network doesn't know what a number is, it doesn't have any concept of a human pulse. It's just learning to map inputs to outputs by minimising error over millions of examples, finding the stable patterns in what would appear to be utter noise to anything simpler.

That distinction is important as these systems scale into medicine, navigation and the sort of thing we use every day. Neural nets aren't minds in a box. They're just blueprints for how complexity can emerge from simple maths. The rest is just data, architecture and a huge amount of tuning.
